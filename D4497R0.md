# Abstract
In C++ we have a number of builtin integer types as well as optional extended integer types, and most recently `_BitInts`.

# Motivation
The current builtin integer types that have properties that can be considered unsafe.
The unsigned integers, for example, silently rollover on overflow and underflow.
Worse though is that for signed this rollover overflow or underflow behavior is UB.
We also have the promotion properties such as `uint8_t + uint8_t -> int`.
In [@P1467R9] we have definitions of _extended floating-point types_, and we need to provide such a taxonomy of integers before defining new types with different properties.
